# 1. Created virtual environment.
- command >> uv venv

# 2. Activated Virtual Enviroment.

- cmd>> .venv\Scripts\Actiavte.ps1

# 3. Installed Django in venv.

- cmd>> uv pip install Django

# 4. Created Djagno project.

- cmd>> django-admin startproject project_name 
- e.g. cmd>>django-admin startproject ToDoList 

# 5. Run server.

- cmd>> python manage.py runserver
